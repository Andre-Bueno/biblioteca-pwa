## Decisões

| Tema | Decisão | Registro |
|---|---|---|
| Identificador de conta | `username` no lugar de `email`; sem cadastro público | ADR 0007 |
| Banco | SQLite em WAL, `synchronous=NORMAL`, FK e `busy_timeout` por conexão | ADR 0007 |
| Senha | Argon2id (t=3, 64 MiB, p=4) e hash dummy | ADR 0007 e ADR 0002 |
| Ponto de montagem | `app/composition.py`, usado por `api/deps.py` e `cli.py` | ADR 0007 e ADR 0001 |
| `ComicInfo.xml` | Ignorado até haver parser seguro (sem `defusedxml`) | Esta entrada; sem ADR |
| Links na biblioteca | Rejeita symlink e junction reais, não o atributo ReparsePoint (OneDrive põe esse atributo em pastas normais) | Esta entrada; teste `test_normal_folder_is_not_mistaken_for_a_link` |

## Discrepâncias encontradas entre código e documentação

| Item | Detalhe |
|---|---|
| PLANO §4 | Previa `User` com `email`. Código usa `username` (ADR 0007). PLANO anotado |
| Mapas (estado da Fase 0) | CODEMAP dizia que `deps.py` não tinha código e que `migrations/` e `cli` não existiam. Corrigido |
| `ItemRepository` | Existe só a porta; não há adaptador nem tabela de `Item` |
| `scan.py` | Usa `datetime.now(UTC)` direto, sem passar pela porta `Clock` |
| Migrador | `migrator.py` acha `migrations/` a partir do arquivo (`parents[3]`). Dentro da imagem, `pip install .` coloca o pacote em `site-packages`, e o caminho só fica certo com cwd `/app`. Não validado |
| `synchronous` | Pedido como "WAL sincrono". Código usa `synchronous=NORMAL`, não `FULL`. ADR 0007 registra `NORMAL` |
| Dependências | `fastapi`, `uvicorn` e `pydantic-settings` sem versão fixa em `pyproject.toml`. ADR 0004 trata de versões travadas no frontend; no backend a trava é pendência M8 |
| Testes de link | Um dos dois casos de link de `test_local_storage.py` pode ser pulado no Windows. Não verificado nesta entrega (sem execução) |
| `infra/AGENTS.md` | Tabela de variáveis não lista as novas `Settings` de sessão e login. Elas não passam pelo compose; estão comentadas em `.env.example` |
| `adapters/AGENTS.md` | Cita `cbr.py`, `epub.py` e `pdf.py` como planejados. Coerente com o estado |
