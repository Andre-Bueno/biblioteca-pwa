# features/reader/manga

Leitor de mangá (`/ler/:itemId`): modos paginado D→E, E→D e vertical (webtoon), toque/deslize/teclado, pré-carregamento das 2 próximas páginas, zoom, retomada e salvamento de progresso (via `shared/progress`). Lógica pura de navegação em `navigation.ts`. Não importar outras features.
